# Mantis для Windows

Настольное приложение для Windows 10 и 11 (64-бит): своё окно, значок на рабочем столе, в меню «Пуск» и у часов. Браузер не нужен. Внутри та же страница Mantis, что на https://mantis.rcmit.ru (вариант A), и встроенный Агент – мост IP-камер и ffmpeg. Ставится установщиком с сайта, без Microsoft Store.

## Как устроено
- `desktop/windows/src-tauri` – приложение на Tauri 2 (Rust). Окно – системный движок Windows WebView2 (Chromium, как Edge): WebGPU и многопоточная нейросеть работают так же, как в Chrome.
- При запуске приложение стартует встроенный Агент (`agent/agent.ts`, собран Bun-ом в `mantis-agent.exe`) с `MANTIS_SHELL=windows` на порту 8797. Агент печатает `MANTIS_READY port=N`, приложение открывает `http://127.0.0.1:N/?desktop=windows`.
- Агент и запущенные им ffmpeg – в одном задании Windows (Job Object): при выходе из Mantis закрываются вместе. Если приложение упало, Агент сам выключается через несколько секунд (`MANTIS_PARENT_PID`). Окон консоли нет.
- Команды оболочки для страницы (`src/desktop.ts`): `app_info`, `keep_awake` (SetThreadExecutionState – компьютер и экран не засыпают), `set_autostart` (запуск при входе в Windows), `quit_app`, `pilot_state`, `open_settings` (разделы «Параметров Windows»), `setup_done`. Разрешены только для 127.0.0.1 (`capabilities/default.json`).
- Камера: своя страница получает доступ без вопроса WebView2. Общий запрет камеры для приложений («Параметры» → «Конфиденциальность» → «Камера») по-прежнему решает Windows.
- Свёрнутое окно не тормозит подсчёт: WebView2 запускается с ключами `--disable-background-timer-throttling`, `--disable-renderer-backgrounding` и т. п. (`BROWSER_ARGS` в `main.rs`).
- Пока идёт подсчёт, крестик сворачивает окно на панель задач, подсчёт продолжается. Без подсчёта крестик закрывает Mantis.
- Значок у часов: «Открыть Mantis», «Главная Mantis», «Подготовка компьютера…», «Проверка компьютера» (`desktop-check.html`), «Выйти из Mantis». Подсказка значка – «Mantis – идёт подсчёт», пока считает.
- Повторный запуск (ярлык, автозапуск) не открывает второе окно, а показывает уже открытое.
- Ссылки на другие сайты и оплата ЮKassa открываются в браузере по умолчанию.
- F5 – обновить страницу.

## Установка и первый запуск
- **Установщик `Mantis-Setup.exe`** (NSIS, по-русски): «Далее» → «Установить» → «Готово» (галочки «Запустить Mantis» и «Ярлык на рабочем столе»). Windows спросит разрешение администратора: Mantis ставится в `C:\Program Files\Mantis` для всех пользователей компьютера.
- Если на компьютере нет WebView2 (старые Windows 10), установщик скачает его сам.
- Установщик добавляет правило брандмауэра «Mantis IP cameras» для `mantis-agent.exe` (частные и доменные сети) – чтобы поиск IP-камер не вызывал окно «Брандмауэр заблокировал некоторые функции». Хуки – `desktop/windows/nsis/hooks.nsh`.
- Обновление – тот же установщик поверх: запущенный Mantis закрывается (установщик спрашивает), настройки и записи сохраняются (данные WebView2 – `%LOCALAPPDATA%\ru.rcmit.mantis`, адрес 127.0.0.1:8797).
- Удаление – «Параметры» → «Приложения» → Mantis → «Удалить». Правило брандмауэра убирается.
- Тихая установка (для администраторов сети): `Mantis-Setup.exe /S`, удаление – `"C:\Program Files\Mantis\uninstall.exe" /S`.
- **«Подготовка компьютера»** (`desktop-setup.html`) – открывается при первом запуске вместо главной страницы и потом из меню значка у часов. Шаги: сеть магазина для IP-камер (`GET /api/lan-check`), камера компьютера или USB-камера, запуск вместе с Windows, сведения о том, что компьютер не будет засыпать. Все шаги необязательные. «Продолжить в Mantis» записывает отметку `%APPDATA%\ru.rcmit.mantis\setup-done`.
- Картинки мастера установки – `desktop/windows/nsis/sidebar.bmp`, `header.bmp` (делает `make-images.py`).

## Сборка
- GitHub Actions: пуш в ветку `desktop-windows` (или `desktop-windows-*`) или Actions → «Mantis для Windows» → Run workflow. Результат – предварительный релиз (prerelease) с `Mantis-Setup.exe`. В CI установщик проверяется на windows-машине: тихая установка, первый запуск (Агент отвечает, снимок экрана – артефакт `shots-windows`), повторный запуск без второго окна, Агент выключается после аварийного закрытия приложения, установка поверх запущенного Mantis, удаление.
- Раздача пользователям: «Деплой в прод» (задача `win-app`) собирает приложение из того же коммита, что сайт, проверяет установку и запуск и выкладывает `Mantis-Setup.exe` на https://mantis.rcmit.ru/downloads/Mantis-Setup.exe. На него ведёт кнопка «Скачать для Windows» на шаге «Источник» → «IP-камера» (docs/agent.md).
- Локально на Windows (Git Bash): `bash desktop/windows/build.sh` → `desktop/windows/out/Mantis-Setup.exe`. Нужны Node 22, Rust с Visual Studio Build Tools, Bun ≥ 1.4.

## Подпись
Сейчас установщик и приложение не подписаны сертификатом. При первом запуске скачанного установщика Windows SmartScreen показывает «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае» (один раз). Установленное приложение запускается без вопросов.
Чтобы предупреждения не было, нужен сертификат для подписи кода (OV или EV, у российских и зарубежных удостоверяющих центров; для облачной подписи – Azure Trusted Signing). Подпись настраивается в `tauri.conf.json` → `bundle.windows` (`certificateThumbprint` или `signCommand`). С OV-сертификатом SmartScreen перестаёт предупреждать, когда у файла накопится репутация; с EV – сразу.
