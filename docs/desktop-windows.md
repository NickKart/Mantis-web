# Mantis для Windows

Настольное приложение Mantis для Windows 10 и 11 (64-бит): своё окно, ярлыки в «Пуске» и на рабочем столе, браузер не нужен. Устроено как Mantis для macOS (docs/desktop-macos.md).

## Как устроено

- Окно Tauri 2 (движок WebView2 – Chromium) открывает страницу у встроенного Mantis Агента: `http://127.0.0.1:8797/?desktop=windows`. Агент даёт заголовки COOP/COEP (многопоточная нейросеть) и мост IP-камер (поиск ONVIF, RTSP → кадры через ffmpeg). Интерфейс и подсчёт – те же файлы, что на сайте.
- Агент – вспомогательная программа внутри приложения (`mantis-agent.exe`, без окна консоли), закрывается вместе с приложением.
- Команды оболочки для страницы (`src/desktop.ts`): `app_info`, `keep_awake` (компьютер и экран не засыпают, пока идёт подсчёт – SetThreadExecutionState), `set_autostart` (запуск при входе в Windows – реестр пользователя), `quit_app`, `pilot_state`.
- Второй запуск (ярлык, автозапуск) открывает уже запущенное окно. Закрытие окна во время подсчёта сворачивает его – подсчёт продолжается. WebView2 запущен без замедления таймеров в свёрнутом окне.
- Меню «Mantis»: Главная, Обновить страницу (F5), Проверка компьютера (Ctrl+Shift+D), Выход. Ссылки на сайты и оплата ЮKassa открываются в браузере.
- Вход – тем же логином и паролем, что на сайте; подписка и почасовая статистика у аккаунта общие.

## Установка

`Mantis-Setup.exe` – мастер по-русски «Далее → Установить», без прав администратора: приложение ставится в `%LOCALAPPDATA%\Mantis`, удаляется через «Параметры → Приложения». Если на компьютере нет WebView2 (старые Windows 10), установщик доустановит его сам (нужен интернет). Тихая установка: `Mantis-Setup.exe /S`.

Установщик пока без цифровой подписи: Windows SmartScreen покажет «Система Windows защитила ваш компьютер» – «Подробнее» → «Выполнить в любом случае». Убирается сертификатом подписи кода.

## Сборка

- Вручную на Windows в Git Bash: `bash desktop/windows/build.sh` → `desktop/windows/out/Mantis-Setup.exe`. Нужны Node 22, Bun ≥ 1.4, Rust (MSVC), Visual Studio Build Tools.
- GitHub Actions: пуш в ветку `desktop-windows` или Actions → «Mantis для Windows» → Run workflow. Сборка на windows-latest, тихая установка, запуск, проверка Агента и COEP, одна копия при повторном запуске, снимок экрана – всё в prerelease.
- Раздача: «Деплой в прод» (задача `win-app`) собирает приложение из того же коммита, что сайт, и выкладывает `Mantis-Setup.exe` на https://mantis.rcmit.ru/downloads/Mantis-Setup.exe. На него ведёт кнопка «Скачать для Windows» в веб-версиях A и B при выборе IP-камеры.
