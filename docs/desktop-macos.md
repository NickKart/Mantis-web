# Mantis для macOS

Настольное приложение: своё окно, значок в Dock и меню. Браузер не нужен. Внутри та же страница Mantis, что на https://mantis.rcmit.ru (вариант A), и встроенный Агент – мост IP-камер и ffmpeg.

## Как устроено
- `desktop/macos/src-tauri` – приложение на Tauri 2 (Rust). Окно – системный движок macOS (WKWebView).
- При запуске приложение стартует встроенный Агент (`agent/agent.ts`, собран Bun-ом) с `MANTIS_SHELL=macos` на порту 8797. Агент печатает `MANTIS_READY port=N`, приложение открывает `http://127.0.0.1:N/?desktop=macos`.
- Агент отдаёт страницу с COOP/COEP (многопоточная нейросеть) и подключает IP-камеры. Закрывается вместе с приложением.
- Команды оболочки для страницы (`src/desktop.ts`): `app_info`, `keep_awake` (caffeinate), `set_autostart` (LaunchAgent), `quit_app`, `pilot_state`. Разрешены только для 127.0.0.1 (`capabilities/default.json`).
- Пока идёт подсчёт, закрытие окна прячет его. Вернуть окно – клик по значку в Dock. Фоновое замедление WKWebView и App Nap отключены.
- Ссылки на другие сайты и оплата ЮKassa открываются в браузере по умолчанию.
- Меню «Mantis»: «Главная Mantis» (⇧⌘H), «Обновить страницу» (⌘R), «Подготовка Mac…», «Проверка компьютера» (⇧⌘D) – страница `desktop-check.html`.

## Установка и первый запуск
- **Образ .dmg.** Окно с фоном: значок Mantis, стрелка и папка «Программы», внизу подсказка для первого запуска. Фон делает `desktop/macos/dmg/make-background.py` (`background.png` и `@2x`), сборка склеивает их в `background.tiff` для Retina. Положения значков – `bundle.macOS.dmg` в `tauri.conf.json`.
- **Перенос в «Программы».** Если приложение запущено не из «Программ» (прямо из образа или «Загрузок», в том числе из временной копии App Translocation), при каждом запуске открывается «Подготовка Mac» с первым шагом «Перенести в «Программы»». Системный вопрос (NSAlert/CFUserNotification) не используем: он рисуется отдельным системным окном и остаётся на экране после перезапуска. Копия создаётся через `ditto`, старая версия уходит в Корзину, с копии снимается отметка «скачано из интернета» (запуск уже разрешён пользователем). Оригинал из «Загрузок» уходит в Корзину, образ отключается, приложение перезапускается из `/Applications`. Если прав на «Программы» нет, появляется системный запрос пароля администратора.
- **«Подготовка Mac»** (`desktop-setup.html`). Открывается при первом запуске вместо главной страницы и потом через меню «Mantis» → «Подготовка Mac…». Шаги:
  1. приложение в «Программах»;
  2. доступ к локальной сети: перед системным вопросом – подсказка, что нажать; проверка – `GET /api/lan-check` у Агента;
  3. камера Mac или USB-камера;
  4. запуск вместе с Mac;
  5. сведения о том, что Mac не будет засыпать во время подсчёта.

  Если доступ запрещён, кнопка открывает нужный раздел «Системных настроек» (`open_settings`). Все шаги необязательные. «Продолжить в Mantis» записывает отметку `~/Library/Application Support/ru.rcmit.mantis/setup-done`.
- Команды для этого: `install_state`, `move_to_applications`, `open_settings`, `setup_done`.

## Установка для пользователя
Один файл `Mantis-Installer.pkg` для всех Mac (Apple Silicon и Intel, macOS 13+). Двойной клик → мастер установки («Продолжить» → «Установить», пароль Mac) → Mantis в «Программах» и сразу запущен. Переносить файлы и распаковывать архивы не нужно.
- `desktop/macos/pkg/`: мастер (`distribution.xml`, тексты `resources/*.html`), скрипты `preinstall` (закрыть запущенный Mantis, убрать прежнюю версию с тем же bundle id; чужое приложение «Mantis.app» переименовывается, не удаляется) и `postinstall` (запустить Mantis от имени пользователя).
- Установка строго в /Applications (BundleIsRelocatable = NO).
- Настройки и записи хранятся в данных пользователя (WebKit, ru.rcmit.mantis, адрес 127.0.0.1:8797) и при обновлении сохраняются.
- `Mantis.dmg` тоже собирается – для тех, кто привык перетаскивать в «Программы».

## Сборка
- GitHub Actions: пуш в ветку `desktop-macos` или Actions → «Mantis для macOS» → Run workflow. Результат – предварительный релиз (prerelease) с `Mantis-Installer.pkg` и `Mantis.dmg`. В CI pkg ставится на macOS-машину (установка и повторная установка поверх), встроенный Агент запускается в обеих архитектурах (Intel – через Rosetta). Prerelease не становится «latest», поэтому прод-сервер его не забирает.
- Раздача пользователям: «Деплой в прод» (задача `mac-app`) собирает приложение из того же коммита, что сайт, и выкладывает `Mantis-Installer.pkg` на https://mantis.rcmit.ru/downloads/Mantis-Installer.pkg. На него ведёт кнопка «Скачать для macOS» на шаге «Источник» → «IP-камера» (docs/agent.md).
- Локально на Mac: `bash desktop/macos/build.sh` (одна версия для всех Mac) или `arm64` / `x64` для быстрой проверки → `desktop/macos/out/`.

## Подпись
Приложение подписывается с усиленной защитой macOS (hardened runtime) и разрешениями из `src-tauri/Entitlements.plist`: камера (`com.apple.security.device.camera` – без него macOS молча запрещает камеру и не показывает Mantis в списке «Камера») и JIT для встроенного Агента. CI проверяет, что разрешение на камеру есть в подписи обоих файлов.

Сейчас приложение подписано ad-hoc, установщик не подписан. macOS не откроет скачанный установщик сразу: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть» (один раз). Приложение, поставленное установщиком, открывается без вопросов.
Для установки без предупреждений нужен аккаунт Apple Developer и два сертификата: Developer ID Application (приложение) и Developer ID Installer (pkg), плюс заверение у Apple (notarytool). Переменные `APPLE_SIGNING_IDENTITY`, `APPLE_INSTALLER_IDENTITY`, `APPLE_ID`, `APPLE_PASSWORD`, `APPLE_TEAM_ID` – в секреты GitHub.

## Проверка компьютера
`desktop-check.html` – одна страница для приложения и для Chrome на том же Mac: многопоточность, WebGPU, скорость нейросети на видеокарте и процессоре, камера, работа в свёрнутом окне. Кнопка «Скопировать результаты» – для сравнения.
